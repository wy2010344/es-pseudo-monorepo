# API 文档索引

各包的 npm 页面与在线文档入口。此前的 `./modules/*.html` 为未生成的 Typedoc 产物，已移除。

## 包列表

| 包 | 说明 |
| --- | --- |
| [mve-core](https://www.npmjs.com/package/mve-core) | 核心运行时：StateHolder、Context、动态列表、根渲染 |
| [mve-dom](https://www.npmjs.com/package/mve-dom) | 直接 DOM 渲染层：`fdom` / `fsvg` / `zdom` |
| [mve-helper](https://www.npmjs.com/package/mve-helper) | 列表/条件渲染、生命周期、Promise 信号、弹层 |
| [mve-dom-helper](https://www.npmjs.com/package/mve-dom-helper) | 表单、存储信号、动画、路由、Canvas |
| [mve-three](https://www.npmjs.com/package/mve-three) | Three.js 视图与 3D 布局 |
| [daisy-mobile-helper](https://www.npmjs.com/package/daisy-mobile-helper) | 移动端 DaisyUI 组件与场景封装 |
| [convex-mve](https://www.npmjs.com/package/convex-mve) | Convex 的 MVE 绑定 |
| [wy-helper](https://www.npmjs.com/package/wy-helper) | 信号、调度与通用工具 |
| [wy-dom-helper](https://www.npmjs.com/package/wy-dom-helper) | DOM 属性更新、事件、尺寸监听 |
